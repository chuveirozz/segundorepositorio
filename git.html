O que é Git e GitHub?

Git

O Git é um sistema de controle de versões que permite acompanhar as alterações realizadas nos arquivos de um projeto

Com ele, podemos registrar alterações, recuperar versões anteriores e trabalhar em equipe.

GitHub

O GitHub é uma plataforma online que permite armazenar e compartilhar repostitórios Git

Por meio dele, podemos comaprtilhar projetos, colaborar com outros desenvolvedores e visualizar o histórico de alterações.

Comandos para praticar

Clique em um comando para abrir sua explicação. No teclado, use tab e enter

1. git init - iniciar um repositório

Execute na pasta do projeto para começar a controlar suas versões.

git init
2. git status - conferir as alterações

Mostra quais arquivos foram modificados e qyaus estao preparadis para o proximo commit

git status
3. git add - preparar os arquivos

Prepara as alterações dos dois arquivos para o próximo commit. Ainda não cria uma versão

git add index.html style.css
4. git commit - registrar uma versão
